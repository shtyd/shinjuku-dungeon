# 新宿駅ナビゲーション (Shinjuku Dungeon)

新宿駅で電車を降りてから、目的地までスムーズに辿り着けるかを試すブラウザゲームです。

**プレイ**: https://shtyd.github.io/shinjuku-dungeon/

## 遊び方

1. ランダムなホーム(JR中央線・山手線・総武線、丸ノ内線、小田急線、京王線、都営地下鉄のいずれか)からスタート
2. ランダムに選ばれた目的地(東口・南口・新南口・西口・思い出横丁・都庁・小田急百貨店・歌舞伎町など)を目指す
3. 各地点では実際の新宿駅の写真が表示され、写っている看板やサインを手がかりに進む方向を選ぶ
4. コインロッカー広場などの行き止まりに迷い込むと引き返しが必要
5. 移動のたびにシミュレーション時間が進み、3割の確率で「混雑で足止め」が発生
6. 到着すると経過時間・最短ルート目安・ミス歩数からランクが表示される
7. 行き先ごとの自己ベストはブラウザにローカル保存される

## 技術構成

- 単一の `index.html`(`shinjuku-navi.html` と同一内容)で完結する、ビルド不要の静的ページ
- 駅構内はノードとエッジのグラフとして表現し、BFSで最短ルートのコストを算出してランク判定に利用
- 各地点の写真は [Wikimedia Commons](https://commons.wikimedia.org/) 掲載の実写真(CC BY / CC BY-SA 等)を `photos/` 配下に同梱。出典は各写真下のリンクから確認可能
- GitHub Pages でそのまま公開(`main` ブランチのルートから配信)

## ファイル構成

```
index.html          公開用エントリーポイント(GitHub Pages)
shinjuku-navi.html   同一内容のソース(Artifact側の作業ファイル)
photos/              各地点の実写真(29枚)
```

## 既知の注意点

- 簡略化した案内図であり、実際の新宿駅の正確な構内図ではありません
- 一部の写真は撮影地・時期が実際のノードと完全一致しない場合がありますが、雰囲気が近いものを選んでいます
